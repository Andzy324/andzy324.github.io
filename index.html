Deployment configuration

GitHub Pages setup required.

This repository contains an Eleventy site, but GitHub Pages is publishing the source branch instead of the generated site.

  1. Open the repository on GitHub and go to Settings → Pages.
  2. Under Build and deployment, set Source to GitHub Actions.
  3. Run the Build and deploy GitHub Pages workflow on the main branch.

The published academic homepage will replace this diagnostic page after the workflow succeeds. See the GitHub Pages publishing guide for detailed instructions.
