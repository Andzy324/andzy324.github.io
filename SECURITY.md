# Security Policy

## Supported versions

Security fixes are applied to the latest state of the `main` branch. This
template does not currently maintain parallel release branches.

| Version                   | Supported |
| ------------------------- | --------- |
| `main`                    | Yes       |
| Older snapshots and forks | No        |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's
[Private Security Advisory form](https://github.com/fusheng-ji/academic-homepage-template/security/advisories/new)
to share a description, reproduction steps, affected files or versions, and any
known mitigations. Do not include real credentials or personal data in a
reproduction.

The maintainers will acknowledge a report when it is reviewed, investigate it,
and coordinate disclosure after a fix is available. Please allow reasonable
time for remediation before discussing the issue publicly.

## Scope

Reports about the template source, build pipeline, GitHub Actions workflows, and
default client-side behavior are in scope. Vulnerabilities introduced only by a
downstream site's custom content, hosting configuration, or third-party services
should be reported to the relevant project or provider.
